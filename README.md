# circuleather
tasks:

het tonen van de voorraad van een artikel aan de buitendienst.

het bestellen van artikelen als een artikel het minimum aantal op voorraad bereikt (met eventuele waarschuwing).

het geven van inzicht aan de directie in de waarde van de voorraad.

Onduidelijk is: Pagina met overzicht van de voorraad (dit is namelijk heel groot).

Duidelijk is: Een tabel met de aanwezige producten in de voorraad, je ziet de hoeveelheid, de locatie, merk etc.
